Proyecto Inicial de Desarrollo Personal

El Objetivo es dejar a disposicion un archivo excel con las tasas de Cambio Oficiales del BCV de Dolar y el Euro

Se ejecuta desde un cronjob e Linux

Por lo pronto esta en un solo directorio, el plan es que tenga una estructura posterior con mayor informacion e ir incorporando
las tasas oficiales indicadas cada dia alrededor de las 5 am UTC-4

Posteiormente desde alli, se crearan las API para ciertas estadisticas (ANUALES, TRIMESTRALES Y MENSUALES) asi como consultas 
para incorporacion de los valores segun una fecha especifica dada
